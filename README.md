# Greek Mythology 100 Atlas

一个本地静态网站，用中文介绍希腊神话中 100 位英语世界常见的神祇与神性人物。

## 在线访问

https://szkailorik.github.io/greek-mythology-100-atlas/

## 功能

- 100 位希腊神祇与神性人物图鉴
- 英文名、中文名、希腊文名和常见英文读音提示
- 点击英文名朗读英语发音，点击希腊文名朗读希腊语读法；详情页提供“英文名 / 希腊文名”发音练习卡，英文语音会优先避开系统里的特殊效果语音
- 搜索、分类筛选和排序；搜索支持英文、中文、希腊文、去重音希腊文转写、领域、故事和艺术家，并提供常用搜索示例按钮
- 首页提供“看图认神练习”，随机展示一位神的生成照片、主符号和神职线索，支持四选一答题、对错反馈、正确率统计、换题、听英文名和打开详情
- 每位神祇包含故事简介、神职领域、象征物
- 每位神祇都有一个代表小故事，提供中文与英文对照文本
- 首页提供面向小朋友的“必记主干谱系”，详情页提供自动谱系路径、简明谱系图和父母、配偶、子女、兄弟姐妹等可点击关系
- 页面使用本地生成的奥林匹斯主题淡背景，并通过半透明面板保证文字可读
- 每位神祇都有单独生成的现代全身形象，突出最主流的神职符号和公众印象
- 每张生成照片上直接显示“主符号 + 核心神职”图像标签，目录卡片另提供“看图记忆点”，帮助小朋友快速记住人物特点
- 详情页在主图下方提供视觉图例，并为每张生成主图提供“先看一眼、构图、主符号、画面元素、背景”解读，帮助观众看懂图像为什么这样设计
- 100 位神祇已全部接入优化后的真实生成位图；同风格 SVG 形象保留为兜底
- 每位神祇包含经典艺术作品知识点：作品名、艺术家、年代和说明
- 详情页先展示生成全身形象，再补充经典油画、雕塑或古典图像参考，并提供现代主图与经典参考的对照阅读

## 本地运行

直接打开 `index.html` 即可使用。

如果希望图片请求和浏览器行为更接近真实网站，可以在项目目录运行：

```bash
python3 -m http.server 8001 --bind 127.0.0.1
```

然后访问：

```text
http://127.0.0.1:8001/index.html
```

## 文件说明

- `index.html`: 页面结构
- `styles.css`: 响应式视觉样式
- `myth-data.js`: 100 条中英对照代表故事、谱系关系与参考来源
- `app.js`: 基础神祇数据、渲染、搜索筛选、详情弹窗、图片加载和发音逻辑
- `assets/backgrounds/olympus-site-background.png`: 本地生成的希腊神话主题背景
- `开发文档.md`: 开发规划和验收标准

## 说明

“前 100 个最有名”采用教学型排序，优先奥林匹斯主神、冥界核心神、泰坦、原初神、海神与风神、命运女神、缪斯和常见人格化神祇。它不是古代官方排名，而是面向学习和浏览的精选目录。
